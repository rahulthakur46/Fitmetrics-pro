## 📌 About
An interactive **Machine Learning powered** fitness analytics dashboard built using real gym member data of **973 athletes**.

Predict calories burned in real-time based on your workout profile!

---

## ✨ Features
- ⚡ **Calorie Prediction** — ML model predicts calories burned live
- 📊 **Overview Dashboard** — Distribution charts & gender analysis
- 🏃 **Workout Analysis** — Deep dive into workout types & frequency
- 🫀 **Health Metrics** — BMI, Fat%, BPM correlation heatmap
- 🗃️ **Data Explorer** — Filter & explore all 973 records
